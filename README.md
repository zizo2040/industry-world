# Alam Al-Sinaa - Electrical & Industrial Supplies

## Enterprise-Grade Website for Electrical & Industrial Supplies Company

### Company Information
- **Arabic Name**: عالم الصناعة للكهرباء والمستلزمات الصناعية
- **English Name**: Alam Al-Sinaa for Electrical & Industrial Supplies
- **Tagline (AR)**: شريككم الموثوق في الحلول الكهربائية والصناعية المتكاملة.
- **Tagline (EN)**: Your Trusted Partner for Integrated Electrical & Industrial Solutions.

### Features
- **Multi-language**: Arabic (RTL) & English (LTR)
- **Dual Theme**: Light & Dark mode
- **SEO Optimized**: Schema.org, Open Graph, Twitter Cards, Sitemap, Robots.txt
- **Security**: CSRF protection, XSS prevention, rate limiting, secure sessions
- **Admin Dashboard**: Products, Categories, Portfolio, Contacts, CMS, SEO, Users management
- **Performance**: Lazy loading, optimized images, caching headers
- **Accessibility**: ARIA labels, keyboard navigation, screen reader support
- **Responsive**: Mobile-first design

### Tech Stack
- **Backend**: PHP 8+ (Vanilla, no frameworks)
- **Database**: MySQL with PDO prepared statements
- **Frontend**: HTML5, CSS3, Vanilla JavaScript (ES6+)
- **No external dependencies**: No frameworks, no libraries, no build tools

### Installation

1. Upload files to your Hostinger hosting
2. Create a MySQL database
3. Import `database/schema.sql` then `database/seed.sql`
4. Update database credentials in your hosting environment variables or configure directly
5. Access the website
6. Admin login: `admin` / `admin123` (change immediately)

### Admin Dashboard
- URL: `/admin/login.php`
- Default credentials: `admin` / `admin123`
