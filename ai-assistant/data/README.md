# Knowledge Base Data Directory

هذا المجلد مخصص لملفات قاعدة المعرفة التي سيستخدمها المساعد.
سيتم تعبئته في **المرحلة الثامنة** (بناء قاعدة المعرفة).

## المحتوى المتوقع

- `company.json` — معلومات الشركة
- `products.json` — قائمة المنتجات
- `services.json` — قائمة الخدمات
- `faq.json` — الأسئلة الشائعة
- `policies.json` — السياسات
